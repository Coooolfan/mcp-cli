## feat

* 新增 `--json info <server>`，一次返回工具名称、描述和完整嵌套 `inputSchema`，支持将包含 `/` 的服务器名称按原值读取，不输出服务器连接配置 https://github.com/Coooolfan/mcp-cli/commit/e56f1f5c2074d766fd105eed704877ca169e18b9
* 新增本地 `package.sh`，支持从 GitHub Release 候选中选择或指定版本，下载六个平台的原生二进制并生成 `manifest.json` 和 `checksums.txt`，可将清单用于后台 `MCP_CLI_MANIFEST`，无需交叉编译 https://github.com/Coooolfan/mcp-cli/commit/e56f1f5c2074d766fd105eed704877ca169e18b9

## fix

* 修复 `info` 和 `call` 未落实工具过滤规则的问题，工具发现遵循 `allowedTools`、`disabledTools`，被禁用的工具无法通过调用命令绕过限制 https://github.com/Coooolfan/mcp-cli/commit/e56f1f5c2074d766fd105eed704877ca169e18b9
* 修复 MCP 返回 `isError=true` 时命令仍以成功状态退出的问题，保留工具输出并返回非零退出码，便于调用方识别业务失败 https://github.com/Coooolfan/mcp-cli/commit/e56f1f5c2074d766fd105eed704877ca169e18b9
